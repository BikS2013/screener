# homebrew-screener

Homebrew tap for [screener](https://github.com/biks2013-tools/screener) — a macOS menu bar app that copies the text of any screen area (English and Greek OCR).

## Installation

```bash
brew tap biks2013-tools/screener
brew install --cask screener
```

The cask also installs `tesseract`, which screener uses for Greek text.

## Upgrade

```bash
brew update
brew upgrade --cask screener
```

## After installation

1. Click the screener icon in the menu bar (it has no Dock icon) and choose **Create Config from Example**. This writes `~/.tool-agents/screener/config.json` and installs the Greek and English OCR data next to it.
2. Grant Screen Recording permission: **System Settings** > **Privacy & Security** > **Screen & System Audio Recording** > enable **screener**. macOS asks on the first capture; quit and reopen screener afterwards.
3. Press **Ctrl+Option+Cmd+T** and drag over any text. It is copied to the clipboard.

## Uninstall

```bash
brew uninstall --cask screener        # removes the app, keeps ~/.tool-agents/screener
brew uninstall --zap --cask screener  # also removes the configuration and OCR data
```

## Maintainers

`Casks/screener.rb` is generated by `package.sh` in [BikS2013/screener](https://github.com/biks2013-tools/screener) (copy kept in its `homebrew-tap/` folder). After each release, copy it here and commit it as `screener <version>`. See that repository's `docs/design/release-runbook.md`.
